# 08-后续版本与参考

## 后续版本方向

后续版本可以按以下方向推进：

| 版本 | 方向 |
|---|---|
| v0.1 | 当前文档摘录批注 |
| v0.2 | 更强锚点恢复和手动重绑 |
| v0.3 | 导出 Markdown 阅读笔记 |
| v0.4 | 全库批注搜索 |
| v0.5 | 标签 / 双链 / 模板 |
| v0.6 | 批注转永久笔记 |

说明：

- 全库筛选不进入明确版本路线，列为无限期延后。
- 最近更新排序和最早创建排序需要等实际使用验证后再决定是否加入。

## 已参考的方向

已参考开源项目：

- `little-pond/axl-light`

可借鉴内容：

- sidecar JSON 存储
- 不污染 Markdown 正文
- CodeMirror 6 Decoration 视觉层
- Reading View DOM 高亮渲染
- 文本锚点和上下文重定位
- 当前文档侧边栏总览

但本插件产品形态不同：

- Axl Light 更像非侵入式高亮和 sticky notes 工具
- 本插件更像 Obsidian 阅读摘录管理面板
