# 06-侧边栏与卡片

## 侧边栏形态

右侧面板是阅读摘录管理面板。

每条批注是一张摘录卡片，而不是协作评论气泡。

卡片包含：

- 原文摘录
- 我的批注
- 标记类型
- 颜色
- 状态
- 创建时间
- 更新时间
- 跳转操作
- 编辑操作
- 删除操作
- 设为已处理操作

卡片示意：

```text
[高亮 · yellow] [未处理] [14:32]

原文
“这里是被选中的正文内容……”

批注
这里写自己的理解、质疑、翻译或方法说明。

跳转   编辑   已处理   删除
```

## 卡片状态模型

卡片状态使用单字段，不使用多个 boolean 组合。

```ts
type SideCommentStatus = "active" | "resolved" | "orphaned";
```

状态含义：

| 状态 | 中文显示 | 含义 | 用户能否手动设置 |
|---|---|---|---|
| `active` | 未处理 | 正常批注，还需要回看或整理 | 可以 |
| `resolved` | 已处理 | 已经看过、整理过或不再需要关注 | 可以 |
| `orphaned` | 已失联 | 原文位置找不到了 | 系统设置为主，后续可支持手动重新定位 |

状态流转：

```text
active -> resolved
resolved -> active
active/resolved -> orphaned
orphaned -> active
```

规则：

- 新建批注默认是 `active`。
- 用户点击“已处理”，状态变成 `resolved`。
- 用户点击“重新打开”，状态回到 `active`。
- 文档修改后锚点找不到，系统标记为 `orphaned`。
- 已失联卡片不删除，继续显示在侧边栏。
- 已失联卡片的正文标记不正常渲染，可以不渲染或渲染为弱提示。
- 手动重新绑定原文位置放到 v0.2，不进入 MVP。

侧边栏状态筛选：

```text
全部 / 未处理 / 已处理 / 已失联
```

卡片视觉：

| 状态 | 视觉 |
|---|---|
| `active` | 正常显示 |
| `resolved` | 降低透明度，显示“已处理” |
| `orphaned` | 警示样式，显示“原文失联” |

## 卡片 UI 信息层级

卡片采用紧凑摘录卡片，不做成大型评论块。

默认展示结构：

```text
[高亮 · yellow] [未处理] [14:32]

“这里是被选中的原文摘录，默认最多显示 3 行……”

我的批注内容，默认最多显示 3 行……

跳转   编辑   已处理   删除
```

信息顺序：

1. 顶部元信息：标记类型、颜色、状态、时间。
2. 原文摘录：必须显示，默认最多 3 行。
3. 我的批注：有内容则显示内容，无内容显示“未填写批注”，默认最多 3 行。
4. 操作区：跳转、编辑、已处理或重新打开、删除。

展开规则：

| 内容 | 默认行为 |
|---|---|
| 原文摘录 | 最多显示 3 行 |
| 批注内容 | 最多显示 3 行 |
| 点击展开 | 展开当前卡片 |
| 再次点击 | 收起当前卡片 |
| 进入编辑 | 自动展开当前卡片 |

状态按钮规则：

| 当前状态 | 按钮 |
|---|---|
| `active` | 显示“已处理” |
| `resolved` | 显示“重新打开” |
| `orphaned` | 显示“已失联”，MVP 不实现重新定位 |

编辑规则：

- 点击“编辑”后，卡片进入编辑态。
- 批注输入框获得焦点。
- 原文摘录仍然可见。
- 标记类型和颜色可以在卡片顶部调整。
- `Enter` 保存。
- `Shift + Enter` 换行。
- `Esc` 取消。

删除规则：

- 删除必须二次确认。
- 删除不会修改 Markdown 正文。
- 删除会移除对应 sidecar 批注数据。

删除确认文案：

```text
删除这条批注？此操作不会修改正文，但会移除对应批注数据。
删除 / 取消
```

## 侧边栏排序和筛选规则

侧边栏 MVP 只管理当前文档批注。

全库筛选不做，并列为无限期延后，不进入明确版本路线。

排序规则：

- 默认且唯一排序方式是按照文章正文从上到下。
- 技术实现是按 `anchor.startOffset` 升序。
- `orphaned` 已失联批注因为没有可靠正文位置，放在列表底部。
- 不做最近更新排序。
- 不做最早创建排序。
- 时间排序需要等实际使用验证后再决定是否加入。

筛选规则：

| 筛选维度 | 选项 |
|---|---|
| 标记类型 | 全部 / 高亮 / 下划线 / 删除线 |
| 状态 | 全部 / 未处理 / 已处理 / 已失联 |

说明：

- MVP 不做颜色筛选。
- 颜色目前只是标记类型默认语义的辅助。
- 搜索、筛选和排序只作用于当前文档。

搜索规则：

- 搜索范围是原文摘录和批注内容。
- 中文按包含匹配。
- 英文大小写不敏感。
- 组合顺序是先搜索，再筛选，最后按正文顺序展示。

空结果文案：

```text
没有匹配的批注
```

计数显示：

无搜索或筛选时：

```text
共 12 条批注
```

有搜索或筛选时：

```text
共 12 条 · 当前显示 4 条
```

## 搜索框和空状态文案

搜索框 placeholder：

```text
搜索当前文档批注...
```

顶部标题：

```text
正文批注
```

顶部副信息：

无搜索或筛选时：

```text
当前文档 · 共 12 条批注
```

有搜索或筛选时：

```text
当前文档 · 共 12 条 · 当前显示 4 条
```

空状态文案：

| 场景 | 文案 |
|---|---|
| 没有打开 Markdown 文件 | 打开一篇 Markdown 笔记后，可以在这里管理正文批注 |
| 当前文档没有批注 | 选中正文后添加高亮、下划线、删除线或评论 |
| 搜索或筛选无结果 | 没有匹配的批注 |
| 当前文档 sidecar 读取失败 | 批注数据读取失败，请检查 `.obsidian-side-comments/` |
| 当前文档存在已失联批注 | 有批注找不到原文位置，仍保留在列表底部 |
