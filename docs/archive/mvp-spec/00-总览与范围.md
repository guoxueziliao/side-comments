# 00-总览与范围

更新时间：2026-05-20

## 插件定位

这是一个面向 Obsidian 的私人正文摘录批注插件。

它不是 PDF 批注插件，也不是 AI 插件，而是用于 Markdown 正文内容的非侵入式批注层。

核心定位：

> 一个不污染 Markdown 的 Obsidian 私人正文摘录批注插件。用户可以对正文片段添加高亮、下划线、删除线和个人批注，并在右侧阅读摘录管理面板中集中查看、搜索、筛选和跳回原文。

主要使用场景：

- 长文精读
- 文献阅读
- 草稿审阅
- 知识沉淀
- 个人阅读摘录
- 对笔记正文进行理解、质疑、翻译、修改建议和补充说明

## 核心原则

### 给自己看

插件服务个人使用，不做多人协作。

第一版不考虑：

- 多人评论
- 协作批注
- 评论回复线程
- 权限系统
- 云端同步协作

### 不污染正文

批注数据不写入 Markdown 原文。

正文中显示的高亮、下划线、删除线都只是视觉层效果，不应该实际写成：

```markdown
==高亮==
<u>下划线</u>
~~删除线~~
```

禁忌：

- 不改写正文
- 不插入脚注
- 不插入 callout
- 不插入 HTML 注释
- 不插入隐藏标记
- 不用 Markdown 语法模拟批注

### 数据独立保存

批注数据保存在独立目录：

```text
.obsidian-side-comments/
```

选择这个目录的原因：

- 透明
- 可长期保存
- 方便迁移
- 方便排查
- 不依赖插件内部私有数据目录
- 适合大知识库长期维护

### 产品形态

插件更像：

> Obsidian 阅读摘录管理面板

而不是：

- Word 审稿栏
- Google Docs 协作评论栏
- Notion 多人评论
- PDF 阅读器批注

正文里的标记只是入口，右侧面板才是主要工作区。

## MVP 功能范围

第一版需要实现：

- 选中文本后出现小工具条
- 添加高亮
- 添加下划线
- 添加删除线
- 添加批注内容
- 当前文档侧边栏批注列表
- 当前文档内搜索批注
- 按正文位置排序
- 按标记类型筛选
- 按状态筛选
- 点击侧边栏卡片跳回正文
- 点击正文标记定位到侧边栏卡片
- 文档修改后尝试重新定位批注
- 找不到原文时标记为已失联
- 不污染 Markdown 正文
- 批注数据保存到 `.obsidian-side-comments/`

## 第一版暂不做

MVP 不做以下功能：

- AI
- PDF
- EPUB
- 多人协作
- 图片批注
- 公式编辑器
- 富文本编辑器
- 全库批注搜索
- 全库筛选
- 最近更新排序
- 最早创建排序
- Markdown 导出
- 标签系统
- 回复串
- 批注转永久笔记
- 云同步
- 权限系统

这些功能可以作为后续版本再考虑，其中全库筛选列为无限期延后，不进入明确版本路线。

## 最终 MVP 一句话

> 一个不污染 Markdown 的 Obsidian 正文摘录批注插件：选中文本后可添加高亮、下划线或删除线，并在右侧阅读摘录管理面板中集中管理批注、搜索、筛选和跳回原文。插件数据保存在 `.obsidian-side-comments/`，采用渐进加载架构，适配几十万篇笔记的大库场景。
