# 04-正文标记与创建规则

## MVP 标记类型

第一版支持三种正文视觉标记：

```ts
type MarkType = "highlight" | "underline" | "strikethrough";
```

默认语义：

| 标记类型 | 默认含义 |
|---|---|
| 高亮 highlight | 重点 / 亮点 |
| 下划线 underline | 疑问 / 待确认 |
| 删除线 strikethrough | 待修改 / 反对 / 可删 |

注意：

- 高亮不是 Markdown 的 `==text==`
- 下划线不是 HTML 的 `<u>text</u>`
- 删除线不是 Markdown 的 `~~text~~`
- 这些标记都只存在于插件的视觉渲染层

## 颜色语义

MVP 先内置五种颜色。

```ts
type MarkColor = "yellow" | "blue" | "red" | "green" | "purple";
```

默认语义：

| 颜色 | 默认含义 |
|---|---|
| yellow | 重点 |
| blue | 疑问 |
| red | 待修改 / 反对 |
| green | 已确认 / 可引用 |
| purple | 批注 / 想法 / 解释 |

第一版可以先使用固定颜色语义，不必须做复杂自定义。

## 正文视觉标记渲染规则

正文标记只做轻量视觉投影，不改变 Markdown 原文。

标记类型：

| 内部字段 | 中文显示 | 正文效果 |
|---|---|---|
| `highlight` | 高亮 | 半透明背景色 |
| `underline` | 下划线 | 彩色下划线 |
| `strikethrough` | 删除线 | 彩色删除线，文字轻微淡化 |

渲染规则：

- 不改变正文布局。
- 不导致行高明显变化。
- 不让正文在渲染后抖动。
- 不写入 Markdown 内容。
- 编辑模式使用 CodeMirror Decoration 投影。
- 阅读视图使用 DOM 投影。

交互规则：

- 点击正文标记后，打开侧边栏。
- 侧边栏滚动到对应卡片。
- 对应卡片短暂闪烁或描边 1 秒。
- hover 正文标记时显示轻量提示：`查看批注`。
- MVP 不在 hover 中展示完整批注内容，避免遮挡正文。

状态渲染：

| 状态 | 正文渲染 |
|---|---|
| `active` | 正常显示标记 |
| `resolved` | 标记仍显示，但降低视觉强度 |
| `orphaned` | 不渲染正文标记，只在侧边栏底部显示 |

## 重复批注和重叠选区规则

批注唯一性以文章位置为准，不能只按选中文本判断。

唯一位置判断：

```ts
filePath + startOffset + endOffset
```

规则：

1. 完全相同位置
   - 如果 `startOffset` 和 `endOffset` 都相同，认为是同一处批注。
   - 不新建重复标记。
   - 直接定位到已有卡片，并进入编辑态。

2. 相同文本，不同位置
   - 允许创建。
   - 文章中同一句话可能出现多次，必须按文章位置区分。

3. 部分重叠选区
   - 允许创建。
   - 不做自动合并。
   - 不做冲突弹窗。

4. 视觉叠加
   - 重叠时按视觉层级叠加。

```text
strikethrough > underline > highlight
```

MVP 不做：

- 不做选区合并。
- 不做批注线程合并。
- 不做复杂重叠编辑器。
