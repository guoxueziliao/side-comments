# 07-插件设置页

## 设置入口

设置项放在 Obsidian 第三方插件设置界面中。

入口：

```text
Obsidian 设置 -> 第三方插件 -> 插件列表 -> 当前插件 -> 设置
```

技术实现使用 Obsidian 插件的 `PluginSettingTab`。

## MVP 设置项

| 设置项 | 默认值 | 说明 |
|---|---|---|
| 创建批注后自动打开侧边栏 | 开 | 创建批注后自动打开右侧阅读摘录管理面板 |
| 显示已处理批注的正文标记 | 开 | `resolved` 批注是否仍在正文显示弱化标记 |
| 内存缓存文档数 | 100 | 最近加载过的 sidecar 文档数 |
| 文档修改后恢复延迟 | 800ms | 锚点恢复 debounce 时间 |
| 数据目录 | `.obsidian-side-comments/` | 只读展示，不允许在 MVP 修改 |

## MVP 不开放

- fuzzy match 阈值
- sidecar hash 规则
- 自定义颜色语义
- 自定义存储目录
- 导出模板
- 卡片模板

原则：

> MVP 设置页只暴露少量运行设置，不开放数据结构、目录、阈值和模板等高级配置；高级配置等真实使用后再决定。
