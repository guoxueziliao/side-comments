# Stage 1: Stabilize MVP

Status: Confirmed

## Goal

Keep the MVP usable for daily local testing and ready for official review feedback.

## Current Result

- The plugin can create annotations in source mode.
- The plugin can create annotations in reading mode.
- The sidebar can show, edit, delete, resolve, search, filter, and jump comments.
- Release `0.1.1` is published through GitHub Releases.
- Official submission has started.
- Local development and local test installation should both be kept.

## Maintenance Rules

- Official review feedback has priority over feature work.
- Validation fixes should be released as patch versions.
- Local test installation should be updated after each build when testing behavior in the vault.
- Do not expand this stage into large new features.

## Exit Condition

This stage is considered functionally complete for now. It remains open only for official review fixes and urgent MVP bugs.
