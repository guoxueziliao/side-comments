# Contributing

Side Comments prioritizes data safety, non-invasive Markdown rendering, current-document usability, large-vault performance, and conservative anchor recovery.

For the MVP, these areas are intentionally out of scope:

- AI features.
- PDF features.
- Cloud sync.
- Multi-user collaboration.
- Full-vault scanning features.
- Rich text editor replacements.
- Any approach that writes annotation syntax into Markdown content.
